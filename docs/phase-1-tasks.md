# Phase 1 — Pure engine + oracle agreement + eval (no database writes)

Nothing is written to the database in this phase. Input is `fixtures/` loaded read-only in memory; output is the `tally:eval` table, the verify and recount CLIs, and green goldens. No Prisma models beyond the template's, no cast path, no UI. The exit bar is "the TypeScript engine agrees with the Python oracle on every ballot, every total, every result and every commitment, in any ballot order." The cloud sandbox may not be able to run Prisma or Playwright; the engine tests do not need either, and CI is the gate for everything that does (D-6).
